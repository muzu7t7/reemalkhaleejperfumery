# Image prompts for product photos

Save each result as `<id>.jpg` in this folder (for example `oil-cambodia.jpg`). It is picked up automatically.

**Format:** 4:5 portrait, about 1600 × 2000 px, JPG at roughly 85% quality (aim for under 400 KB).
**Tip:** generate all items of one type in the same session or with the same style reference, so the catalogue looks like one shoot.
**Tip:** keep labels blank. Image generators garble text, and the shop already shows the name beside the photo.

## Shared style block (paste at the start of every prompt)

> Luxury product photograph, quiet-luxury editorial style, soft warm window light from the left with gentle shadows, shallow depth of field, 85mm macro lens, ultra-detailed, photorealistic. Single subject, centred, generous empty space around it, seamless warm backdrop. Subtle brass accents. No text, no logos, no watermark, no people, no hands.

## Negative prompt (if your tool supports one)

> text, letters, logos, watermark, label text, people, hands, clutter, extra objects, cartoon, illustration, 3D render look, oversaturated, distorted bottle, deformed glass, duplicate objects
